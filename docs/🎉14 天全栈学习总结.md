🎉14 天全栈学习总结

1. 基础 CRUD 与 RESTful 架构：封装统一响应结构 Result<T>，基于 Spring Data JPA / MyBatis-Plus 完成基础设施构建。
2. 高性能缓存与安全认证：集成 Redis 处理热点数据，结合 Spring Security + JWT 实现无状态 Token 身份认证与全局拦截。
3. 前端 SPA 与 动态 Layout：使用 Vue 3 (Vite) + Element Plus + Vue Router 4 搭建通用后台管理布局及全局路由守卫（beforeEach）。
4. RBAC 细粒度权限控制：设计角色/权限模型，编写 Vue 3 自定义指令 v-permission 实现按钮级别的控制与隐显。
5. 分布式文件存储：集成 MinIO 对象存储，实现防冲突文件上传与线上预览。
6. 企业级数据处理：配置 MyBatis-Plus 分页插件，结合 VO 实现多表 Join 联表查询与前端 <el-pagination> 联动。
7. 业务审计与异步解耦：使用 AOP + 自定义注解 @Log 拦截业务请求，结合 Spring @Async 线程池与 RabbitMQ 消息队列 实现异步日志处理与高并发削峰填谷。
8. 生产环境工程化：使用 Nginx 解决前端 History 路由刷新 404，通过 Multi-stage Dockerfile 和 docker-compose.yml 实现全栈一键容器化编排。
