# 🗓️ 7 天全栈学习总结

| **天数**     | **核心主题**                  | **实现的关键技术点**                                                           |
| ---------- | ------------------------- | ---------------------------------------------------------------------- |
| **Day 01** | **Spring Boot 基础工程**      | RESTful API 架构、依赖注入与分层设计（Controller / Service / Mapper）。               |
| **Day 02** | **统一响应与异常处理**             | `Result<T>` 统一 API 数据结构、全局异常拦截器与 HTTP 状态码规范。                           |
| **Day 03** | **MyBatis-Plus & MySQL**  | Docker 容器化数据库部署、ORM 映射、LambdaQueryWrapper 动态 SQL 与条件查询。                |
| **Day 04** | **Redis 高性能缓存**           | Cache-Aside 旁路缓存模式、TTL 自动失效、主动缓存清除（Evict）与 Spring Bean 冲突解耦。           |
| **Day 05** | **Vue 3 + Vite 前端搭建**     | 前端脚手架构建、Element Plus UI 库、Axios 封装与 CORS 跨域治理。                         |
| **Day 06** | **前端 CRUD & 交互**          | Element Plus 表格/弹窗/表单交互、自增主键策略（`@TableId(type = IdType.AUTO)`）与全栈数据同步。 |
| **Day 07** | **Spring Security + JWT** | 无状态认证防线、JWT 签发与解析过滤器、Axios 自动化 Token 拦截与登录态管理。                         |
